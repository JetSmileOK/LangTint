LangTint превращает **панель задач Windows и указатель мыши в фоновый индикатор раскладки**. Текущую раскладку видно боковым зрением ещё до первого символа.

[English](README.md) · [Релизы](https://github.com/JetSmileOK/LangTint/releases) · [Roadmap](ROADMAP.md) · [Приватность](docs/privacy.md) · [Безопасность](SECURITY.md)

## Идея за 3 секунды

| Активная раскладка | Панель задач | Указатель |
| --- | --- | --- |
| **English** | светло-голубая `#B7E9FF` | голубые **Arrow** и **Hand** с тёмным контуром |
| **Русский** | обычная панель Windows | обычная схема курсоров Windows |

Текстовый курсор, изменение размера, ожидание и остальные системные курсоры не перекрашиваются. LangTint меняет настоящую панель Explorer напрямую — **без полупрозрачного overlay поверх значков и текста**.

> **Без исправления текста. Без угадывания языка. Без постоянного polling. Просто видно раскладку.**

## Чем отличается подход

Большинство помощников заставляют смотреть на маленький `ENG/RUS`, рисуют дополнительный бейдж у каретки или исправляют ошибку уже после набора. LangTint делает иначе: превращает состояние раскладки в элемент интерфейса, который и так постоянно перед глазами.

| Подход | Что замечает пользователь | Когда |
| --- | --- | --- |
| системный код языка | маленький `ENG/RUS/...` | только если специально посмотреть |
| бейдж у каретки/курсора | дополнительный элемент | когда смотришь на него |
| автоисправление | переписанный текст | после начала набора |
| **LangTint** | панель задач + штатный указатель | **до набора, боковым зрением** |

LangTint не анализирует набранный текст, не читает буфер обмена и не пытается угадывать намерение пользователя.

## Установка

Обычному пользователю нужен ровно **один файл**:

**`LangTint-Setup.exe`**

Скачайте его в разделе [Releases](https://github.com/JetSmileOK/LangTint/releases) и запустите двойным кликом. Установщик:

- ставит LangTint только для текущего пользователя Windows;
- **не требует прав администратора**;
- предлагает автозапуск вместе с Windows и запуск после установки;
- перед включением автозапуска выполняет безопасную проверку совместимости;
- при ошибке откатывает установку;
- добавляет штатное удаление через **Параметры → Приложения → Установленные приложения**;
- оставляет установленную папку минимальной;
- при удалении восстанавливает обычную схему курсоров и убирает автозапуск.

Пока бесплатная цифровая подпись не активирована, тестовые сборки **не подписаны**, поэтому Windows может показывать предупреждение о неизвестном издателе или репутации файла.

## Совместимость

Текущий кандидат v1.7.1 намеренно поддерживает:

- Windows 10 x64, сборки **14393–19045**;
- штатную панель задач Explorer;
- одну и больше установленных раскладок, включая RU/EN;
- Alt+Shift, Ctrl+Shift и Win+Space.

Windows 11, ARM64 и сторонние замены taskbar пока не заявляются как поддерживаемые до реальной проверки. См. [ROADMAP.md](ROADMAP.md).

## Почему нагрузка минимальна

- событийная обработка смены раскладки и активного окна;
- прямая композиция taskbar без overlay-окна;
- отдельный visual worker вне keyboard callback;
- нет постоянного polling раскладки;
- нет mouse hook;
- нет телеметрии и сетевого клиента;
- нет чтения буфера обмена и сохранения набранного текста.

Низкоуровневый keyboard hook получает события Windows только для отслеживания комбинаций переключения раскладки. Точный объём описан в [Privacy](docs/privacy.md).

## Проверки качества

Runtime содержит **матрицу из 100 сценариев отказа**: комбинации переключения, локализованные названия индикатора Windows, владелец taskbar, восстановление при старте, гонки событий и fail-safe поведение.

Отдельно проверяются ресурсы установщика, хеши исходников, Windows x64 PE, автозапуск/удаление, supply-chain pins и уже скомпилированный Setup. Готовый установщик действительно запускается на Windows CI, чтобы ловить ошибки старта до выпуска кандидата.

CI не подменяет реальную проверку Explorer: перед стабильным выпуском кандидат проходит живой desktop-тест.

## Roadmap

Самые важные следующие шаги:

1. подписанные стабильные релизы через SignPath Foundation;
2. реальная проверка и поддержка Windows 11;
3. назначение цветов для разных языков вместо фиксированного EN/RU поведения;
4. WinGet/Scoop после стабильного подписанного релиза.

См. [ROADMAP.md](ROADMAP.md). За нужные функции можно голосовать реакцией 👍 в Issues.

## Сборка из исходников

Проверенный toolchain: **Go 1.27.1**.

```sh
cd source
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags="-H=windowsgui -s -w" -o ../build/LangTint.exe .
```

Исходник установщика: [`packaging/installer/LangTint.iss`](packaging/installer/LangTint.iss).
