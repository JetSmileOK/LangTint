# LangTint

**Раскладку видно ещё до первого набранного слова.**

[![Build](https://github.com/JetSmileOK/colore_of_aungage/actions/workflows/build.yml/badge.svg)](https://github.com/JetSmileOK/colore_of_aungage/actions/workflows/build.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

LangTint — небольшая утилита Windows, которая превращает активную раскладку в **заметный периферическим зрением цветовой сигнал**. Вместо того чтобы обнаружить `ghbdtn` после набора, состояние раскладки видно заранее.

[English](README.md) · [Релизы](https://github.com/JetSmileOK/colore_of_aungage/releases) · [Приватность](docs/privacy.md) · [Безопасность](SECURITY.md)

## Как выглядит

| Раскладка | Панель задач | Указатель |
| --- | --- | --- |
| **English** | голубая `#B7E9FF` | голубые **стрелка** и **рука** с тёмным контуром |
| **Русская** | обычная панель Windows | обычная схема курсоров Windows |

Текстовый курсор, resize, busy и остальные служебные указатели не перекрашиваются и сохраняют нормальную контрастность. Полупрозрачного окна поверх значков панели нет.

## В чём идея

Маленький `ENG/RUS` легко не заметить. LangTint не исправляет уже написанный текст и не пытается угадывать язык — он делает состояние раскладки видимым заранее.

**Без автокоррекции. Без угадывания текста. Без постоянного polling. Просто видимая раскладка.**

## Скачать

Используйте опубликованный файл из [Releases](https://github.com/JetSmileOK/colore_of_aungage/releases). Успешные [CI-сборки](https://github.com/JetSmileOK/colore_of_aungage/actions/workflows/build.yml) также содержат неподписанные тестовые артефакты.

Текущая публичная базовая версия репозитория — **v1.5.3 для Windows 10 x64**. Расширение совместимости и более дружелюбный установщик проходят отдельную проверку; неподтверждённые платформы не объявляются поддерживаемыми.

Сейчас бинарники **не подписаны доверенной подписью издателя**, поэтому Windows может показать предупреждение. Интеграция SignPath Foundation подготовлена, но подпись не будет заявлена до фактического одобрения проекта и проверки полученного сертификата.

## Что происходит в фоне

- Событийная обработка переключения раскладки и смены активного окна.
- Прямое оформление панели задач — без overlay-окна.
- Визуальные операции вынесены из keyboard callback.
- Постоянного опроса раскладки нет.
- Mouse hook нет.
- Телеметрии и сетевого клиента приложения нет.
- Набираемый текст не сохраняется, буфер обмена не читается.

Подробнее: [Приватность](docs/privacy.md).

## Исходники

Код проекта находится в [`source/`](source/). Два крупных Win32-файла перед тестами и сборкой детерминированно восстанавливаются из byte-exact фрагментов в `tools/internal/`.

```sh
cd source
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./...
```

Структура репозитория:

```text
source/       код и тесты
packaging/    файлы и метаданные выпуска
tools/        сборка/проверки; внутренние фрагменты спрятаны здесь
docs/         документация и инженерные материалы
.github/      CI и шаблоны GitHub
```
