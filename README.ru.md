# LangTint

### Раскладку видно ещё до первого набранного слова.

Небольшая утилита для Windows: **панель задач и указатель мыши показывают активную раскладку цветом**. Не исправляет написанное за вас и не пытается угадать язык текста.

[English](README.md) · [Релизы](https://github.com/JetSmileOK/colore_of_aungage/releases) · [MIT](LICENSE)

**EN:** голубой фон панели и голубые стрелка/рука с тёмным контуром. **RU:** обычная панель и пользовательская схема указателей. Текстовый курсор и служебные указатели остаются штатными. Полупрозрачного окна поверх значков нет.

## Установка

Скачайте ZIP из опубликованного релиза, распакуйте полностью и запустите `RUN_ALL_AND_INSTALL.cmd` или `TaskbarLayoutTint_v1_5_3.exe`. Файл `.manifest` должен находиться рядом с EXE. Если опубликованного релиза пока нет, проверочные сборки доступны в успешных запусках Actions; для их скачивания GitHub может потребовать вход.

Удаление: `UNINSTALL.cmd`. Проверка состояния: `STATUS.cmd`. Это текущий ZIP-пакет со встроенной установкой, **не новый графический Setup и не portable-приложение**.

## Совместимость этой ветки

В GitHub сохранён исходный код **v1.5.3: Windows 10 x64, обычная панель Explorer, RU/EN**. Его установочный тест делает два переключения Alt+Shift, поэтому требует включённого Alt+Shift и соответствующего цикла из двух раскладок. Поддержка Windows 11, ARM64, сторонних панелей и других конфигураций не обещается. Подготовленный отдельно архив v1.6 не подменяется этими изменениями оформления и выпуска.

## Подпись и безопасность

**Бесплатная подпись SignPath подготовлена технически, но ещё не одобрена и не активирована. Сборки пока неподписанные.** Предупреждение Windows возможно. SHA-256 подтверждает целостность файла, но не заменяет цифровую подпись издателя. Не отключайте защиту Windows ради установки.

[Политика подписи](CODE_SIGNING_POLICY.md) · [Подготовка SignPath](docs/SIGNPATH_SETUP.md) · [Приватность](PRIVACY.md)

## Что происходит в фоне

Программа реагирует на горячие клавиши и смену активного окна. Постоянного опроса раскладки нет. Набираемый текст и буфер обмена не сохраняются; сетевого кода и телеметрии приложения нет. При этом клавиатурный обработчик получает события нажатий — это не означает абсолютно нулевую нагрузку. Короткий CPU-тест установщика не доказывает расход батареи на всех компьютерах.

## Проверки и исходники

[Процесс выпуска](docs/RELEASING.md) описывает проверку хешей исходников, тестирование, сборку, упаковку и создание черновика релиза. CI не заменяет проверку настоящего Explorer/DWM на Windows. Рабочую логику панели и курсоров эта публикационная доработка не меняет.

Для воспроизведения старой сборки сохранён Go 1.23.2. Это исторический, а не актуальный toolchain; переход на поддерживаемую версию должен пройти отдельную проверку до широкого выпуска.

Нашли проблему — приложите версию Windows, раскладки, способ переключения и отчёт **без личных данных**. Звезда помогает людям с такой же проблемой найти LangTint.
