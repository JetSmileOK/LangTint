LangTint делает активную раскладку заметной **боковым зрением**. Вместо того чтобы обнаружить ошибку после набора `ghbdtn`, раскладку видно ещё до первого символа.

[English](README.md) · [Релизы](https://github.com/JetSmileOK/LangTint/releases) · [Приватность](docs/privacy.md) · [Безопасность](SECURITY.md)

## Что видно

| Активная раскладка | Панель задач | Курсор |
| --- | --- | --- |
| **English** | светло-голубая `#B7E9FF` | голубые **Arrow** и **Hand** с тёмным контуром |
| **Русский** | обычная панель Windows | обычная схема курсоров Windows |

Текстовый курсор, изменение размера, ожидание и остальные системные курсоры не перекрашиваются. Панель задач меняется напрямую через композицию Windows — **никакого полупрозрачного оверлея поверх значков и текста**.

> **Без исправления текста. Без угадывания языка. Без постоянного опроса. Просто видно раскладку.**

## Установка

Обычному пользователю нужен один файл:

**`LangTint-Setup-x64.exe`**

Скачайте его в разделе [Releases](https://github.com/JetSmileOK/LangTint/releases) и запустите двойным кликом. Установщик:

- ставит LangTint только для текущего пользователя Windows;
- **не требует прав администратора**;
- предлагает галочку **Запускать LangTint автоматически вместе с Windows**;
- предлагает **Запустить LangTint сейчас** после установки;
- до включения автозапуска выполняет безопасный self-test без переключения вашей раскладки;
- при ошибке теста откатывает установку и не оставляет автозапуск;
- добавляет обычное удаление через **Параметры → Приложения → Установленные приложения**;
- при удалении убирает автозапуск и восстанавливает штатную схему курсоров Windows.

Установщик имеет современную светлую/тёмную тему и фирменную иконку LangTint. Пока бесплатная цифровая подпись не активирована, тестовые сборки **не подписаны**, поэтому Windows может показывать предупреждение о неизвестном издателе или репутации файла.

## Совместимость

Кандидат v1.7.0 намеренно поддерживает:

- Windows 10 x64, сборки **14393–19045** (за пределами проверенного диапазона runtime отказывает безопасно);
- штатную панель задач Explorer;
- одну, две, три и больше установленных раскладок, включая RU/EN;
- Alt+Shift, Ctrl+Shift и Win+Space.

Windows 11, ARM64 и сторонние замены панели задач пока не выдаются за поддерживаемые. Неизвестная конфигурация должна безопасно отказаться от установки, а не «вроде работать».

## Почему нагрузка минимальна

- Событийная обработка смены раскладки и активного окна.
- Прямая композиция панели задач без overlay-окна.
- Отдельный worker для визуальных операций вне keyboard callback.
- Нет постоянного polling раскладки.
- Нет mouse hook.
- Нет телеметрии и сетевого клиента.
- Нет чтения буфера обмена и сохранения набранного текста.

Низкоуровневый keyboard hook получает события клавиатуры, чтобы замечать комбинации переключения раскладки. Точный объём описан в [Privacy](docs/privacy.md).

## Проверки качества

В runtime v1.7 есть **матрица из 100 различных сценариев отказа**: комбинации переключения, локализованные названия индикатора Windows, проверка владельца taskbar, восстановление при старте, гонки событий и fail-safe поведение.

Отдельно проверяются политика установщика, хеши исходников, Windows x64 PE, автозапуск и удаление, состав релиза и закрепление внешних GitHub Actions по SHA. CI закрепляет проверенный релизный toolchain **Go 1.27.1** для воспроизводимости; обновление toolchain проводится отдельным изменением.

CI не подменяет реальную визуальную проверку Explorer. Перед стабильным релизом кандидат обязательно проверяется на настоящем Windows 10 desktop.

## Сборка из исходников

Проверенный релизный toolchain: **Go 1.27.1**.

```sh
cd source
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags="-H=windowsgui -s -w" -o ../build/LangTint.exe .
```

Исходник установщика: [`packaging/installer/LangTint.iss`](packaging/installer/LangTint.iss). CI получает официальный Inno Setup 7.1.0 только после проверки закреплённого SHA-256 и Authenticode издателя.
